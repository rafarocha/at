🔎 Como abrir o RDV e o Log de Urna (.dat)

Esses dois arquivos vêm no pacote de arquivos de uma urna (baixados do portal do TSE ou copiados da mídia de resultado). Têm a mesma extensão .dat, mas são formatos completamente diferentes — e é por isso que um abre no bloco de notas e o outro vira "lixo" na tela. Abaixo, o que cada um é e o comando certo para abrir.

❓ Por que o arquivo não abriu

O erro mais comum — e por que aconteceu

Você tentou abrir RDV_o03220pe2531301500328_1791484080073.dat como se fosse texto. O RDV não é texto: ele é um arquivo binário no formato ASN.1 DER (o mesmo tipo de codificação usada em certificados digitais). Abrir binário num editor de texto mostra símbolos embaralhados, porque o editor tenta interpretar bytes de controle como letras.

Como confirmar o tipo de qualquer arquivo .dat no Linux/macOS: 
# diz o que o arquivo realmente é
file RDV_o03220pe2531301500328_1791484080073.dat
# RDV  -> "data"        (binário — não é pra abrir como texto)
# logd -> "ISO-8859 text" (texto — pode abrir no editor)
ArquivoO que éFormatoAbre como texto?
logd.datLog de Urna — diário de eventos do diaTexto (ISO-8859-1), separado por TAB✅ Sim
rdv.dat / RDV_…datRegistro Digital do Voto — a lista de votos embaralhadaBinário ASN.1 DER❌ Não
bu.datBoletim de Urna — totais por candidatoBinário ASN.1 DER❌ Não

🗳️ O que é o RDV (Registro Digital do Voto)

E o que ele NÃO é
  • É a lista de todos os votos daquela urna, cargo por cargo, em ordem embaralhada — propositalmente, para que seja impossível descobrir em quem a 1ª, a 2ª ou qualquer pessoa votou (garante o sigilo do voto).
  • Não tem nome, título nem qualquer dado do eleitor. Só os números digitados.
  • Serve para recontagem/auditoria: somando o RDV você tem que chegar exatamente nos totais do Boletim de Urna (bu.dat).
No seu arquivo, cada voto confirmado vira um registro. Dá para contar quantos existem — e esse número bate com o total de Voto confirmado para [...] que aparece no Log de Urna da mesma seção.

🧰 Como abrir e conferir o RDV

Do mais simples ao mais completo

Opção A — Jeito oficial (recomendado): visualizador do TSE

1
Baixe o RDV — Leitor de arquivos na página de dados abertos do TSE (dados de urna). É um programa gráfico oficial que lê o rdv.dat e mostra os votos por cargo, já organizados.
2
Abra o programa, aponte para o seu RDV_…dat e ele exibe a tabela de votos. Nenhum comando necessário.
Para quem só quer ver o conteúdo sem instalar nada técnico, essa é a via. As opções abaixo são para quem quer inspecionar o arquivo "na unha".

Opção B — Linha de comando: provar que é ASN.1 DER e lê-lo

O openssl (já vem no Linux/macOS) decodifica a estrutura inteira: 

# mostra a árvore ASN.1 (SEQUENCE, INTEGER, ENUMERATED, strings...)
openssl asn1parse -inform DER -in RDV_o03220pe2531301500328_1791484080073.dat | less

# só o cabeçalho legível (versão do app, município, seção)
openssl asn1parse -inform DER -in RDV_...dat | grep GENERALSTRING

# conta os registros de voto (aproxima o total de votos da urna)
openssl asn1parse -inform DER -in RDV_...dat | grep -c ENUMERATED
Se o openssl listar SEQUENCE, INTEGER, ENUMERATED e GENERALSTRING sem erro, está confirmado: o arquivo é um ASN.1 DER íntegro. Se desse erro de parsing, o arquivo estaria corrompido.

Opção C — Espiar os trechos legíveis (sem decodificar tudo)

# extrai só as "ilhas" de texto embutidas no binário
strings -n 3 RDV_...dat | head

# exemplo de saída: data/hora de encerramento, versão do app e seção:
#   20261004T185800
#   10.23.0.0 - Praia da Barra do Cahy
#   ZPE150WKS03

Opção D — Verificar a assinatura/integridade

O pacote da urna traz arquivos de hash/assinatura (hash.dat, *.vsc). A conferência oficial de integridade é feita pelas ferramentas do TSE; o openssl asn1parse acima já serve para provar que o RDV está estruturalmente válido.

📜 O Log de Urna (logd.dat) — esse abre fácil

É texto puro — a matéria-prima do painel de Desempenho

Diferente do RDV, o logd.dat é texto. Cada linha é um evento do dia, com 6 campos separados por TAB: 

data e hora        │ severidade │ nº urna │ subsistema │ mensagem │ hash

04/10/2026 08:03:31  INFO   02318954   VOTA   O voto do eleitor foi computado   78B0CE1A...
O arquivo está em ISO-8859-1 (Latin-1), não em UTF-8. Se os acentos aparecerem errados, converta: 
iconv -f ISO-8859-1 -t UTF-8 logd.dat > logd-utf8.txt

Eventos úteis para medir desempenho

Mensagem no logO que marca

No projeto, o script scripts/parse_logd.py lê exatamente esses eventos e gera dados-desempenho.json, que alimenta as páginas de desempenho por seção (328 · 329 · 330). O scripts/parse_rdv.py faz o mesmo com o RDV (contagem de votos por cargo) e o build_desempenho.py embute os dois no HTML: 
python3 scripts/parse_logd.py logs/zone/150/logd.dat   # log -> indicadores
python3 scripts/parse_rdv.py RDV_...dat                # RDV -> mapa de votos (opcional)
python3 scripts/build_desempenho.py                    # embute tudo no HTML

✅ Resumo rápido

  • logd.dat → texto. Abre no editor; converta de Latin-1 se precisar.
  • RDV / bu.dat → binário ASN.1 DER. Use o leitor oficial do TSE (Opção A) ou openssl asn1parse (Opção B). Nunca abre direito num editor de texto.
  • Na dúvida sobre qualquer .dat, rode file nome.dat primeiro.
Sigilo: o RDV é embaralhado de propósito e não contém dados pessoais. Mesmo assim, trate os arquivos de urna com cuidado e só os publique de fontes/portais oficiais.
